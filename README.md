# 楠·聚焦搜索 (nan-spotlight)

macOS 聚焦（Spotlight）风格的 Obsidian 插件：**既是全局搜索，又是文件管理器**。

- 作者：@楠
- 版权：是小楠呐
- 版本：v1.0

## 功能

### 1. 界面
- 平滑的**亚克力透明背景**（毛玻璃 + 背景模糊，模糊程度可在设置中调整）。
- **从中间向上下展开 / 闭合**的开合动画。
- 上下两个区域：上为**搜索区**，下为**文件区**（默认显示全部文件夹）。

### 2. 搜索
- 与 Obsidian 原生搜索一致的选项与功能：**匹配大小写、全词匹配、正则表达式**。
- 支持搜索操作符（**中英文前缀通用**）：`folder:`/`文件夹:`（搜文件夹）、`other:`/`其他:`（搜 PDF 等非 Markdown 文件）、`file:`/`名称:`（按文件名）、`path:`/`路径:`、`tag:`/`标签:`、`line:`/`行:`、`section:`/`章节:`、`block:`/`块:`，以及 `"短语"` 精确匹配。
- **文件夹搜索**：`folder:名称`（或 `文件夹:名称`）匹配文件夹，点击结果会**直接在聚焦页打开该文件夹**。
- **其他格式搜索**：`其他:文件名`（或 `other:文件名`）搜索 PDF、图片等非 Markdown 文件，独立于普通搜索；普通关键词搜索只搜 Markdown 正文。
- **点击搜索框**进入输入状态时，才显示搜索帮助与选项，把底部更多空间留给文件区；输入内容后隐藏文件区、仅显示搜索结果；无匹配时显示「未找到匹配结果」。

### 3. 文件管理
- 默认显示全部文件夹，按 Windows 资源管理器的方式管理。
- 可在**列表视图**与**小图标视图**之间切换（切换结果会保存）。
- **单击**文件/文件夹会**高亮选中**；**快速双击**打开笔记或进入文件夹。
- 顶部工具栏提供**新建笔记 / 新建文件夹**按钮；文件夹右键菜单、空白处右键同样提供新建。
- **右键**弹出与 Obsidian 原生文件管理器一致的菜单（在新标签页打开、创建副本、移动到、复制路径、使用默认应用打开、在系统资源管理器中显示、重命名、删除等）。

### 4. 收藏夹
- 文件/文件夹右键菜单含「**收藏到收藏夹** / 从收藏夹移除」。
- 默认 **Ctrl + Shift + Space** 快速打开/关闭**收藏夹**界面（与聚焦搜索同款亚克力与动画）。
- 收藏夹内双击文件打开、双击文件夹跳转到对应目录；点击星标或右键可取消收藏。

### 5. 快捷键
- 默认 **Ctrl + Space** 呼出/关闭聚焦搜索界面。
- 默认 **Ctrl + Shift + Space** 呼出/关闭收藏夹。
- 均可在插件设置中点击快捷键按钮重新录制组合键。
- Markdown 笔记默认**新标签页打开**（可在设置中关闭）；PDF/图片等非 Markdown 文件**始终新标签页打开**。

> 注意：Windows 中文输入法默认也会占用 `Ctrl+Space` 来切换输入法，若无法呼出，请到插件设置中改成其它组合键。

## 安装

### 方式一：手动安装（构建产物）
1. 下载本目录，将包含 `manifest.json`、`main.js`、`styles.css` 的整个文件夹放入你的仓库：
   `<你的仓库>/.obsidian/plugins/nan-spotlight/`
2. 在 Obsidian 中进入 `设置 → 第三方插件`，启用「楠·聚焦搜索」。

### 方式二：从源码构建
```bash
pnpm install   # 或 npm install
pnpm build     # 生成 main.js
```

## 使用
1. 按下 `Ctrl+Space` 呼出聚焦搜索界面；按下 `Ctrl+Shift+Space` 呼出收藏夹。
2. 点击搜索框，输入关键词搜索；输入 `file:`、`tag:` 等操作符可进一步过滤。
3. 下方文件区单击选中、双击进入/打开、右键使用原生菜单（含收藏）。
4. `Esc` 或点击面板外部区域关闭。
